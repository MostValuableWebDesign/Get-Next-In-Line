We now need a production-quality provider abstraction.

Implement the following.

1. Expand the workforce provider contract.

Create a provider interface/service contract similar to:

```ts
interface WorkforceProvider {
  readonly definition: WorkforceProviderDefinition;

  getConnectionStatus(context: ProviderContext): Promise<ProviderConnectionStatus>;

  listEmployees(context: ProviderContext): Promise<NormalizedEmployee[]>;

  getEmployee?(
    context: ProviderContext,
    externalEmployeeId: string
  ): Promise<NormalizedEmployee | null>;

  listContractors?(
    context: ProviderContext
  ): Promise<NormalizedContractor[]>;

  listPayrollRuns?(
    context: ProviderContext,
    options?: PayrollQueryOptions
  ): Promise<NormalizedPayrollRun[]>;

  getCompensation?(
    context: ProviderContext,
    externalEmployeeId: string
  ): Promise<NormalizedCompensation | null>;
}
```

Use clean TypeScript domain types.

2. Add normalized workforce domain models.

At minimum create normalized models for:

* Employee
* Contractor
* Payroll run
* Compensation
* Provider connection status
* Provider sync result

Normalized employee should support fields such as:

* providerId
* externalId
* firstName
* lastName
* displayName
* email
* phone
* employmentType
* employmentStatus
* jobTitle
* hireDate
* terminationDate
* rawUpdatedAt

Do NOT expose provider-specific response objects to the React UI.

3. Add a provider resolver.

Create a service such as:

```ts
getWorkforceProvider(providerId: string): WorkforceProvider
```

Today this may only resolve `"gusto"`, but the system must support future providers without changing Operations screens.

4. Add persistent capability ownership.

Do NOT determine capability ownership with:


Add the appropriate unique constraints so a tenant cannot accidentally have multiple primary owners for the same capability.

Capabilities currently include:

* employees

* payroll
* compensation
* onboarding
* benefits
* tax_documents
* time_tracking
* time_off

Operations overview must read the persisted assignment instead of automatically choosing the first compatible provider.
