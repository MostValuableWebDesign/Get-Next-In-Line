---
name: Twilio CTA vetting
description: Requirements for keeping the GNIL SMS opt-in flow verifiable during A2P campaign review.
---

The A2P campaign's CTA must point reviewers to the actual public booking flow, not only the privacy policy. The flow should visibly identify the sender/business, use an optional unchecked checkbox, require a mobile number for SMS consent, show message frequency/rates and STOP/HELP language, and link directly to the privacy policy and terms.

**Why:** A campaign can be rejected for an unverifiable CTA even when the privacy policy itself is compliant; reviewers must be able to follow the submitted message-flow URL and see the opt-in control.

**How to apply:** When resubmitting, use a live booking URL for an active business and describe the exact checkbox text and navigation steps in the campaign's message-flow field. Publish frontend changes before submitting.
